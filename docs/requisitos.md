**Projeto:** Sigaa de Bolso.
Este documento define as especificações técnicas, funcionalidades esperadas e restrições do projeto Sigaa de Bolso

## 1. Requisitos Funcionais:
Ações que o sistema deve ser capaz de executar para atender as necessidades do usuário

O sistema deve permitir o login do usuário utilizando as mesmas credenciais (usuário e senha) do SIGAA oficial. 
O aplicativo deve extrair e baixar as informações acadêmicas do usuário (grade, notas e faltas) no momento do login. 
O sistema deve exibir a grade horária semanal do aluno, detalhando a disciplina, o horário e o local.
O aplicativo deve exibir uma barra indicando a quantidade de faltas acumuladas e o limite permitido por disciplina.
O aplicativo deve enviar notificações preventivas caso o aluno atinja um percentual de faltas próximo ao limite de reprovação. 
O sistema deve checar periodicamente o portal e enviar uma notificação push quando uma nova nota for lançada.
O sistema deve notificar o aluno sobre cancelamentos de aulas ou recados postados pelos professores no mural virtual da turma. 
O sistema deve disponibilizar uma tela de chat interativa para comunicação com o Assistente Virtual (Mestre JM IA). 
O Assistente Virtual deve processar perguntas em linguagem natural e fornecer tutoriais ou explicações sobre processos acadêmicos burocráticos.
